# Egypt Field Guide (phone app)

Offline web app for a family trip to Egypt, 21 to 31 October 2026, served from GitHub Pages at https://edemaistre.github.io/egypt-guide/. It is plain static files: `index.html`, `app.js`, `app.css`, `data.json`, a service worker (`sw.js`), photos in `img/`, maps and diagrams in `svg/`, fonts in `fonts/`, audio in `audio/` and the PDF version. All paths are relative, so the site works under the `/egypt-guide/` sub-path. There are no external requests, no analytics and no build step at runtime. On an iPhone, open the link in Safari, add it to the Home Screen, open it from there and tap "Save the guide" and "Save all audio" once on Wi-Fi.

This folder is generated. The sources (site texts, episode list, photo manifests, maps, audio) live in the project folder one level up, and `tools/build_app.py` rebuilds this folder from them: `uv run --quiet --with pyyaml --with pillow python tools/build_app.py`. The generator never deletes: files that are no longer part of the build are moved to the project's `scratch/archive/`. Each build gets a new version string, so installed phones pick up the new service worker and show a "Reload" prompt; "Save the guide" then fetches only the files that changed.
